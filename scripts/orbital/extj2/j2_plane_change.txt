== E. drift is a 1-D control in a 2-D error space ==
   For planes (i_s, Om_s) and (i_t, Om_t),
     cos(di_rel) = cos i_s cos i_t + sin i_s sin i_t cos(dOm)
   which is MAXIMISED (di_rel minimised) at dOm = 0, where it gives
   di_rel = |i_s - i_t| EXACTLY. So |di| is a hard FLOOR: drift moves
   dOm and can null the node component completely, but it can never
   take di_rel below the inclination difference.
