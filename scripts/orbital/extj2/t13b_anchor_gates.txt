not the anchor's: `pufferl.__init__` has random.seed / np.random.seed /

WHAT THE ANCHOR IS
    lambda * CE(pi_root || pi_theta) on a FIXED dataset of tight-cell states
    (1200 windows x 64 steps = 76,800 states) rolled from the root on
    TIGHT_5k1. Forward CE against the root's FULL 31-way softmax at tau=1 —
    not argmax labels, not MSE (Rusu Table 1: KL >= NLL >> MSE), not sharpened
    (tau=0.01 is folklore for unnormalised Q-value teachers). lambda CONSTANT,
    no decay: the anchor IS the init (CLEAR), not a teacher to wean off.
    Default lambda 0.02, the LOW end of the synthesis's 0.01-0.05.

THE LSTM QUESTION, SETTLED BY READING THE TRAINER
    `train()` forwards minibatches with lstm_h=None, lstm_c=None, and
    `evaluate()` advances buffer rows every bptt_horizon steps REGARDLESS of
    episode boundaries. The trainer therefore already evaluates every 64-step
    window from a ZERO hidden state wherever it sits in an episode. The anchor
    dataset is cut on that same cadence and both networks are forwarded
    zero-init. R2D2 stored-state/burn-in machinery would have anchored a
    DIFFERENT function than the one PPO's gradient shapes — silently, with
    every number still looking plausible.
